LinkedList Implementation

Step through the program one line at a time. Watch the frames (each function call's variables) and the objects they point to. Keys: →/Space next, ← back.

A linked list stores each item in its own Node, and each node points to the next one (next). The list itself only knows the first node, head. Nothing is shifted: operations just change arrows. But reaching position i means following i arrows from the head. Pick an operation with the buttons; the later ones start with the list already built.

How it works

Walking to a position (_traverse(index)): start at head and follow next index times. O(n).

add(value) (at the front):

  1. Make a new node that points to the current first node.
  2. Make it the new head. O(1): no walking.

append(value) (at the end):

  1. Make a new node. If the list is empty, it becomes the head.
  2. Otherwise walk to the last node and point its next at the new node. O(n).

remove(index):

  1. At index 0, move head to the second node.
  2. Otherwise walk to the node before index (prev) and point prev.next past the removed node. Nothing points to it any more, so it's gone.

insert(index, value):

  1. At index 0, this is add.
  2. Otherwise walk to prev, point the new node at prev.next first, then point prev.next at the new node. In the other order, the rest of the list would be lost.

    Frames and objects
    
    
    
      
    Frames live on the call stack. Every function call gets a new
         frame holding its own variables, and the frame is pushed onto the
         call stack (the newest call is at the bottom of the list below).
         When a call returns, its frame is popped and the caller carries on where it left off.
    
      
    Recursion pushes one frame per call until it reaches the base case,
         then unwinds as each call returns. The stack is limited: Python allows about 1000
         frames by default (sys.getrecursionlimit()). A recursive function that never
         reaches its base case keeps pushing frames until the stack runs out and Python stops with
         RecursionError: maximum recursion depth exceeded, a stack overflow.
