Introduction and history

What is Python?

“Python is a widely used general-purpose, high-level programming language. Its design philosophy emphasizes code readability.” wiki

“Python is powerful… and fast; plays well with others; runs everywhere; is friendly & easy to learn; is Open.” python.org

Why Use Python?

Readable and interpreted

  • Not compiled (computer executes in order)
  • Easy to develop, debug, and share

Easy to learn, powerful, and fast

  • High-level and dynamically typed
  • Interfaces with compiled languages (e.g., C, C++, Fortran)
  • Versitile libraries “under the hood”

Open and frees

  • Community support and development
  • Skills transfer without overhead (no site lisence)

Example uses for Python

  • General programming (e.g., clock applet in Ubuntu)
  • Video games (e.g., Ubisoft in Montreal)
  • Web development (e.g., Pinterest, Instagram)
  • Data analysis (e.g., visulalization, multi dimensional data, statisitics)
  • Scripting (e.g,. automating system tasks, smart file manipulation)

Getting started

Python Source Files (.py)

All Python source files use the extension .py (for C source files we use the extension .c).

A basic example is:

# hello.py
print("Hello, World")

We can run this file with:

$ python3 ./hello.py

Notice that we did not have to compile hello.py first. Python is an interpreted language, so we run the source file directly with the Python interpreter.

The difference between interpreted and compiled languages will be discussed below.

Python Virtual Environments

When you write C programs, you mostly think about:

  • the compiler (gcc)
  • your source files
  • and maybe a few installed libraries

With Python, we also have to think about environments.

What Is a Python Environment?

A Python environment is:

A specific Python installation plus a collection of installed Python packages.

You can think of it as a self-contained workspace for Python code.

Each environment has:

  • its own Python version (e.g. 3.10, 3.11)
  • its own set of installed packages (e.g. numpy, scipy, matplotlib; common packages used for scientific computing)

Why Do We Need Environments?

Different projects often need different packages or different versions of the same package.

Examples:

  • Project A needs scipy version 1.26
  • Project B needs scipy version 2.0
  • Your course might need a stable set of packages for the whole term

If everything is installed globally in one place, these requirements can conflict.

Environments solve this by letting each project have:

Its own isolated set of Python packages.

Python vs C

Conceptual Differences

Before we begin writing Python programs, it is important to understand how Python differs from the C language you used in your previous course. Although both are imperative programming languages, their design goals and programming models are quite different.

Interpreted vs. Compiled

One of the biggest differences between C and Python is how programs run.
This affects performance, debugging, portability, and development workflow.

What Happens in a Compiled Language (like C)?

C is a compiled language, which means:

  1. You write source code (.c files).
  2. A compiler (e.g., gcc) translates it into machine code for a specific CPU.
  3. The result is a binary executable (e.g., a.out, program.exe).
  4. When you run the program, the CPU executes the precompiled machine instructions directly.

Advantages of Compilation

  • Very fast execution (close to the hardware).
  • Compiler catches many errors before the program runs.
  • Memory layout and performance optimizations are predictable.
  • Good for system programming, embedded devices, real-time applications.

Disadvantages

  • Requires a compilation step before running.
  • You must recompile for different operating systems or CPU architectures.
  • Debugging can sometimes require special tools.

What Happens in an Interpreted Language (like Python)?

Python is an interpreted language, meaning:

  1. You write source code (.py files).
  2. The Python interpreter reads your program line by line, translating it into actions at runtime.
  3. Python first converts code to bytecode, then executes it using the Python Virtual Machine (PVM).

This process looks like:

your_program.py →\rightarrow Python Interpreter →\rightarrow bytecode →\rightarrow Python Virtual Machine → output

Advantages of Interpretation

  • No compilation phase → run code immediately.
  • Rapid development and experimentation (great for learning, prototyping, data science).
  • Highly portable: the same Python file runs on Windows, macOS, Linux without recompiling.
  • Easier debugging—errors reference the exact line of Python code.

Disadvantages

  • Usually slower than compiled code because each instruction is processed at runtime.
  • Higher memory overhead.
  • Some optimizations that compilers do automatically are not available.

For more information about bytecode and the Python Virtual Machine (PVM), check out this article here.

Why Does This Matter?

When transitioning from C to Python:

  • You will notice faster iteration: write code →\rightarrow run immediately →\rightarrow fix mistakes quickly.
  • You will lose the performance advantages of compiled languages.
  • You will encounter runtime type errors instead of compile-time type errors.
  • Python encourages exploration; C encourages precision and planning.

These differences shape how programs are designed and how you work as a programmer.

Indentation vs. Curly Braces and Semicolons

  • C uses {} to define code blocks and ; to terminate statements.
  • Python uses indentation to structure code blocks and does not require semicolons.

Example:

C Syntac

if (x > 0) {
    printf("Positive\n");
}

Python Syntac

if x > 0:
    print("Positive")

Dynamic vs. Static Typing

  • C requires explicit type declarations (e.g., int x;, double y;).
  • Python determines the type of a variable at runtime.
  • This allows faster development but requires you to be careful with variable usage.

Example:

C Static Typing

int x = 10;
double y = 3.14;

Python Dyamic Typing

x = 10
y = 3.14

C Types vs. Python Native Types

Python does not require explicit type declarations like C does, but it still has rich built-in types. The table below compares common C types with their closest Python equivalents.

C Type Example Declaration Python Equivalent Notes
int int x = 10; int Python integers have arbitrary precision (no overflow).
float float f = 3.14f; float Python floats are double-precision (like C double).
double double d = 9.81; float Python has no separate double type; float is 64-bit IEEE-754.
char char c = 'A'; str Python has no char; single-character strings are used instead.
char[] (C-string) char s[] = "hi"; str Python strings are immutable and Unicode-based.
bool / _Bool bool flag = true; bool Python booleans are True and False.
Arrays int a[10]; list Python lists can grow/shrink dynamically and hold mixed types.
Pointers int *p; N/A Python does not expose pointers directly; everything is a reference.
struct struct point { ... }; class / dict Python uses classes or dictionaries for structured data.
void* Generic pointer N/A Python variables can store any object dynamically.

Key Takeaways:

  • Python simplifies type usage by automatically determining types at runtime.
  • Python integers do not overflow, unlike 32-bit C integers.
  • Python float corresponds to C’s double, not float.
  • Python has no direct equivalent to pointers, but all variables are references to objects.
  • Strings are much more flexible and Unicode-aware compared to C strings.
# Demonstrating Python types
x = 10          # int
y = 3.14        # float (double precision)
c = 'A'         # str of length 1
s = "Hello"     # str
flag = True     # bool

# Print the type of each of the variables assigned above using the built-in type() function
print(x, ":", type(x))
print(y, ":", type(y))
print(c, ":", type(c))
print(s, ":", type(s))
print(flag, ":", type(flag))

3.14 : <class 'float'>
A : <class 'str'>
Hello : <class 'str'>

No Header Files / No Required main() Function

In C, programs begin at main() and often require header files.

In Python, execution starts at the top of the script, and no header files are needed.

Python has a main() convention, (optional and will be covered in more detail later in the course).

Example:

C Syntax

#include <stdio.h>

int main(void) {
    printf("Hello World\n");
    return 0;
}

Python Syntax

print("Hello World")

Standard Libraries: #include vs import

In both C and Python, you rarely write everything from scratch.
Instead, you use standard libraries that provide useful functions.

C uses header files (e.g. stdio.h).
Python uses modules (e.g. math, random).

C: Using #include

In C, you bring in standard library functions using #include and a header file:

#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}

Python: Using import

In Python, you bring in extra functionality using import and a module name (a module is simply a .py file):

import math

print(math.sqrt(9))

You can also import specific names:

from math import sqrt

print(sqrt(9))

In the above example

  • sqrt is imported directly into the current file’s namespace (A namespace is like a labeled box of names. math is one box, my file is another box. import lets me use names from another box.).
  • You don’t need to write math.sqrt, just sqrt.

Input and Output

In C, you might write:

int x;
printf("Enter a number: ");
scanf("%d", &x);

In Python:

x = input("Enter a number: ")  # returns a string

If you want a number, you must convert it:

x = int(input("Enter an integer: "))

Functions: Definition and Use

Python functions differ from C functions in several important ways.

Key Differences at a Glance

  • Python does not require function prototypes
  • Python does not specify return types
  • Python does not specify parameter types
  • Python functions can return multiple values
  • Python functions are defined using indentation, not braces

Function Definition Syntax

C Syntax

#include <stdio.h>

int square(int x) {
    return x * x;
}

int main(void) {
    int result = square(5);
    printf("%d\n", result);
    return 0;
}

Python Syntax

In Python, indentation is syntactic, not stylistic.

def square(x):
    return x * x

result = square(5)
print(result)

Warning: Incorrect indentation will causes errors:

def absolute(x):
if x < 0:
return -x
else:
return x
Output
  Cell In[2], line 2
    if x < 0:
    ^
IndentationError: expected an indented block after function definition on line 1

Here is the corrected version with proper indentation:

def absolute(x):
    if x < 0:
        return -x
    else:
        return x

print(absolute(-5))   # 5
print(absolute(3))    # 3
Output
5
3
