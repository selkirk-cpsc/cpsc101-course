More Python Basics

Comments in Python

Python uses the # symbol for comments.

# Print a message to the screen
print("Hello")

x = 5  # store the value 5 in x

Basic Expressions

Python supports familiar operators:

  • Arithmetic: +, -, *, /, // (integer division), % (mod), ** (power)
  • Comparison: ==, !=, <, >, <=, >=
  • Logical: and, or, not

In C we use &&, ||, ! for logical operators; in Python, we use the English words and, or, not.

Addition, Multiplication, and Division

x = 7
y = 3

print("x + y =", x + y) # Addition
print("x - y =", x - y) # Subtraction
print("x * y =", x * y) # Multiplication
Output
x + y = 10
x - y = 4
x * y = 21
print("x / y =", x / y)     # float division
print("x // y =", x // y)   # integer division
Output
x / y = 2.3333333333333335
x // y = 2

Modulo %

# Integer Modulo
x = 3
y = 4

# Float Modulo
# x = 3.
# y = 4

print("x % y =", x % y)
Output
x % y = 3

Power

x = 2
y = 3

print("x ** y =", x ** y)   # power
Output
x ** y = 8

Warning: The caret symbol (^) defines a different operation then double asterisks (**):

x = 2
y = 3

print("x ^ y =", x ^ y)   # Can you remember from CPSC100 what this operation is?
Output
x ^ y = 1

The caret symbol (^) denotes XOR bit operation:

2=1022 = 10_2, 3=1123 = 11_2,

$2\char`\^ 3 = 10_2 \char`\^ 11_2 = 01_2 = 1$

Don’t worry if this causes you to scratch your head at first. Just remember that in Python, exponentiation uses double asterisks (**), while the caret (^) is used for a different operation.

Comparison Operators (==, !=, <, >, <=, >=)

x = 7
y = 3

print("x > y:", x > y)
print("x == y:", x == y)
Output
x > y: True
x == y: False

Remark: In Python, True and False are their own data type (bool), which means they behave like values that can be stored, compared, and returned from functions. They are used to control program flow, such as in if statements, loops, and comparisons.

Logical Operations (and, or, not)

Boolean values can also be combined using logical operators like and, or, and not to build more complex conditions.

x = 7
y = 3

print("x > 0 and y > 3:", x > 0 and y > 3)
print("x > 0 or y < 0:", x > 0 or y < 3)
print("not (x > y):", not (x > y))
Output
x > 0 and y > 3: False
x > 0 or y < 0: True
not (x > y): False

Scientific Calculator

The math module provides access to common mathematical functions and constants in Python.

It includes tools for arithmetic, trigonometry, logarithms, and constants like pi and e, allowing you to perform more advanced mathematical calculations than basic operators alone.

import math
# Create a variable for pi
pi = math.pi
print(pi)

print(math.cos(pi))

print(math.exp(1))
Output
3.141592653589793
-1.0
2.718281828459045

Random

The random module provides tools for generating random numbers and making random choices in Python. It is commonly used in simulations, games, sampling, and testing, where unpredictable or varied behavior is useful.

Like other modules, it must be imported first, and its functions are accessed using dot notation, such as random.random() or random.randint().

import random

# Generate a random integer between 1 and 100 (inclusive)
number = random.randint(1, 100)

print(number)
Output
75

Remark: Each time this program runs, it may produce a different result, even though the code is the same.

Unlike in C, you do not need to manually set a random seed, Python automatically seeds the random number generator for you when the program starts.

Strings

Python Strings

A string is a built-in Python type used to store text.

You can think of a string as a sequence of characters:

  • Characters have a defined order (position 0, 1, 2, …)
  • You can access individual characters and slices
  • Strings support many useful operations for working with text

Creating Strings

You create a string using quotes. In Python, you can use single or double quotes:

empty = ""
greeting = "Hello"
name = 'Alice'
sentence = "Python is fun!"

For now, just be consistent (many people prefer double quotes).

String — Public Interface

Because strings are immutable, all operations either read from the string or produce a new string — nothing ever modifies the original.

Operation Syntax Description
Access character s[i] Character at index i
Length len(s) Number of characters
Slice s[start:end] Sub-string from start to end-1
Concatenate s1 + s2 Join two strings into a new string
Repeat s * n New string with s repeated n times
Membership x in s True if x is a sub-string of s
Iterate for c in s: Loop over characters one at a time
Case s.upper() / s.lower() New string in upper or lower case
Strip s.strip() New string with leading/trailing whitespace removed
Replace s.replace(old, new) New string with all occurrences of old swapped for new

Notice there is no s[i] = x — that would require mutation, which strings do not support.

Indexing (Accessing Characters)

String positions (indices) start at 0.

word = "Python"

first = word[0]   # 'P'
second = word[1]  # 'y'
last = word[5]    # 'n'

print("first:", first)
print("second:", second)
print("last:", last)
Output
first: P
second: y
last: n

Remark: If you use an index that is out of range, Python will raise an error:

word = "Hi"

word[2]  # IndexError: string index out of range
Output
---------------------------------------------------------------------------
IndexError                                Traceback (most recent call last)
Cell In[12], line 3
      1 word = "Hi"
----> 3 word[2]  # IndexError: string index out of range

IndexError: string index out of range

Length of a String

You can use the built in len() function to find the number of characters in a string.

word = "Python"
count = len(word)    # 6
print(count)
Output
6

Strings Are Immutable

Strings are immutable, which means you cannot change a string “in place”.

This does not work:

word = "Python"

word[0] = "J"   # TypeError: 'str' object does not support item assignment
Output
---------------------------------------------------------------------------
TypeError                                 Traceback (most recent call last)
Cell In[14], line 3
      1 word = "Python"
----> 3 word[0] = "J"   # TypeError: 'str' object does not support item assignment

TypeError: 'str' object does not support item assignment

To “change” a string, you create a new string:

word = "Python"
new_word = word + "3"
print(new_word)   # "Python3"
Output
Python3

Concatenation (Joining Strings)

You can join strings using the + operator:

first = "Hello"
second = "World"

combined = first + " " + second
print(combined)    # "Hello World"
Output
Hello World

You can also repeat strings using the * operator:

line = "-" * 10
print(line)        # "----------"
Output
----------

Slicing (Sub-strings)

You can take a slice (a sub-string) using start:end.

name = "Ryan T. Bradshaw"

middle = name[5:6]   # "T.""
first = name[:4]  # "Ryan"
last = name[8:]    # [40, 50]

print("full name:", name)
print("middle:", middle)
print("first:", first)
print("last:", last)
Output
full name: Ryan T. Bradshaw
middle: T
first: Ryan
last: Bradshaw

Built-In Methods

In Python, some operations are built into an object (like a string). These operations are called methods.

A method looks like this:

name = "Hello World"
NAME = name.upper() # <-- calling the method .upper() on the string "Hello World"
print(NAME)
Output
HELLO WORLD

Very simple mental model for now:

A method is like a function that “belongs to” an object, and we call it using

object.method(...).

We will talk about the deeper “object-oriented” ideas later.

For now, just remember: many Python values (strings and lists) have built-in methods that we call using the dot operator (.).

Built-In Methods for Strings

upper and lower: Create all upper or lower case copies respectively:

s = "Hello, World"

print(s.upper())   # "HELLO, WORLD"
print(s.lower())   # "hello, world"
Output
HELLO, WORLD
hello, world

Remark: Since strings are immutable, upper() and lower() do not change the original string. Instead, they return a new string.

s = "Hello World"
s.upper()

print(s) # "Hellow World" <--- s doesn't change
Output
Hello World

strip: Remove leading and trailing whitespace:

s = "   hello   "
print(s)

clean = s.strip()
print(clean)       # "hello"
Output
   hello   
hello

replace: Create a new string with parts replaced:

s = "I like Java"
new_s = s.replace("Java", "Python")
print(new_s)       # "I like Python"
Output
I like Python

Control Flow

Overview

We will look at:

  • if, elif, else
  • while loops
  • for loops

The main difference from C is indentation instead of braces {}.

if / elif / else

if x > 0:
    # ...
elif x == 0:
    # ...
else:
    # ...
# Example: classify a number by it's sign

x = int(input("Choose a number"))
print(x)

if x > 0:
    print("Positive")
elif x == 0:
    print("Zero")
else:
    print("Negative")
Output
4
Positive

while Loops

i = 0
while i < 5:
    print(i)
    i += 1
# while loop example: sum of first n integers

n = 5
total = 0
i = 1

while i <= n:
    total += i
    i += 1

print("Sum of first", n, "integers is", total)
Output
Sum of first 5 integers is 15

for Loops

C Syntax:

for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

Python Syntax:

for i in range(5):
    print(i)

range(5) generates the sequence 0, 1, 2, 3, 4.

Looping over Iterables

In Python, for loops iterate over sequences (also called iterables), such as lists or strings.

# Looping over a list

print("Looping over a list:")
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
Output
Looping over a list:
apple
banana
cherry
# Looping over a string

print("Looping over a string:")
course_code = "CPSC101"
for letter in course_code:
    print(letter)
Output
Looping over a string:
C
P
S
C
1
0
1

range() with Arguments

range() can take one, two, or three arguments — similar to a C for loop counter:

Call Equivalent C loop Produces
range(n) for (int i=0; i<n; i++) 0, 1, ..., n-1
range(start, stop) for (int i=start; i<stop; i++) start, ..., stop-1
range(start, stop, step) for (int i=start; i<stop; i+=step) every step from start 
# Count from 0 to 4
for i in range(5):
    print(i, end=" ")
print()

# Count from 2 to 7
for i in range(2, 8):
    print(i, end=" ")
print()

# Count in steps of 2
for i in range(0, 10, 2):
    print(i, end=" ")
print()

# Count backwards
for i in range(5, 0, -1):
    print(i, end=" ")
print()
Output
0 1 2 3 4 
2 3 4 5 6 7 
0 2 4 6 8 
5 4 3 2 1

enumerate() — Index and Value Together

In C, when you loop over an array you naturally have the index i available. In Python’s for x in collection: loop, you only get the value.

enumerate() gives you both the index and the value at the same time:

fruits = ["apple", "banana", "cherry"]

# Without enumerate — have to manage the index manually
i = 0
for fruit in fruits:
    print(i, fruit)
    i += 1
Output
0 apple
1 banana
2 cherry
# With enumerate — index and value together, cleanly
for i, fruit in enumerate(fruits):
    print(i, fruit)
Output
0 apple
1 banana
2 cherry

break and continue

You already know these from C — they work the same way in Python:

Keyword Effect
break Exit the loop immediately
continue Skip the rest of this iteration, move to the next 
# break: stop as soon as we find a negative number
numbers = [3, 7, -2, 5, -8, 1]

for n in numbers:
    if n < 0:
        print("Found negative:", n)
        break
    print(n)
Output
3
7
Found negative: -2
# continue: skip negative numbers, print only positive ones
numbers = [3, -1, 7, -4, 2]

for n in numbers:
    if n < 0:
        continue
    print(n)
Output
3
7
2
