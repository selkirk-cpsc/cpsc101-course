Class Definitions

The Basics

A class definition begins the keyword class, followed by its name NameOfClass, ending with colon ::

class NameOfClass:

Within the class block, we have three main ingredents:

  • __init__ (initialiser/constructor)
  • attributes (data definitions)
  • methods (behaviour)
class NameOfClass:
    __init__ # initialiser/constructor
    attributes
    methods

Remark: Following the naming convention from the Python docs:

Class names should normally use the CapWords (CamelCase) convention.

Example: LabSample Class

Lets construct a LabSample class.

class LabSample:

    def __init__(self, sample_id, units):
        self.sample_id = sample_id
        self.units = units
        self.measurements = []  # empty list of floats

    def add_measurement(self, value):
        """Add a single measurement."""
        self.measurements.append(float(value))

Lets break this down the above code into it’s main parts:

  • __init__
  • self
  • attributes
  • methods

The initializer __init__

The special method __init__ is the initializer (sometimes called a constructor).

  • It specifies what information must be provided when we create a new LabSample.
  • In this case, we must provide a sample_id and units.
  • The initializer also sets up an empty list measurements so the object is ready to store measurements.

Inside __init__, the values are stored on the object using self:

  • self.sample_id = sample_id
  • self.units = units
  • self.measurements = []

Referring to one-self

self is the name we use (by convention) for this object. Inside the class, self lets you refer to the specific instance you are building or working with.

In __init__:

def __init__(self, sample_id, units):
    self.sample_id = sample_id
    self.units = units
    self.measurements = []
  • Think of self as the new LabSample object being created.
  • self.sample_id, self.units, and self.measurements are the object’s own stored data.

Attributes

The LabSample class has three attributes (also called instance variables):

  • sample_id : an identifier for the sample (e.g., "PH-017")
  • units : the measurement units (e.g., "pH", "V", "g")
  • measurements : a list that stores the numeric readings for that sample

Attributes are defined within the __init__ method:

def __init__(self, sample_id, units):
    self.sample_id = sample_id
    self.units = units
    self.measurements = []

Methods

Methods define the behaviour of our class. In the case of LabSample we introduced an add_measurement method. This method allows us to add measurements to the list attribute self.measurements.

def add_measurement(self, value):
    """Add a single measurement."""
    self.measurements.append(float(value))

Objects (Instances)

Creating Objects (Instances) of a Class

  • New objects (instances) of a class are created by calling the class name like a function.
  • You pass in the values needed by __init__ (except for self, which Python supplies automatically).

Example: LabSample Instances

Lets create two LabSample instances:

s1 = LabSample("PH-017", "pH")
s2 = LabSample("V-204", "V")

  • The variable s1 holds a reference to a LabSample object whose attributes store:

    • sample_id = "PH-017"
    • units = "pH"
    • measurements = [] (an empty list to start)

  • The variable s2 references a different LabSample object with:

    • sample_id = "V-204"
    • units = "V"
    • measurements = []

  • These variables reference separate objects.

    • They have the same kinds of attributes and can use the same methods (like add_measurement), but each object stores its own values.

Accessing Object Attributes and Methods

Attributes

We can access attributes held by s1 and s2 by using the dot notation:

# Accessing sample id
s1_id = s1.sample_id
s2_id = s2.sample_id

print(f"s1 sample id: {s1_id}")
print(f"s2 sample id: {s2_id}")
Output
s1 sample id: PH-017
s2 sample id: V-204
# Accessing units
s1_units = s1.units
s2_units = s2.units

print(f"s1 units: {s1_units}")
print(f"s2 units: {s2_units}")
Output
s1 units: pH
s2 units: V
# Accessing measurements
s1_measurements = s1.measurements
s2_measurements = s2.measurements

print(f"s1 measurements: {s1_measurements}")
print(f"s2 measurements: {s2_measurements}")
Output
s1 measurements: []
s2 measurements: []

Methods

As we saw in the previous code block, the measurements lists for s1 and s2 are empty. It would be useful if the LabSample class included some built-in behaviour for adding measurements to these samples.

That is the purpose of the add_measurement method. Using dot notation, we can call add_measurement to store new measurements in our s1 and s2 objects.

# Adding measuresments to s1
s1.add_measurement(6.98)
s1.add_measurement(7.01)
s1.add_measurement(6.99)

# Adding measurements to s2
s2.add_measurement(4.93)
s2.add_measurement(4.88)
s2.add_measurement(4.91)

print(f"s1 measurements: {s1_measurements}")
print(f"s2 measurements: {s2_measurements}")
Output
s1 measurements: [6.98, 7.01, 6.99]
s2 measurements: [4.93, 4.88, 4.91]

Object Assignment

Identifying Objects

When assigning an object to a variable it comes with its own unique identifier in memory.

  • Even if two samples had the same sample_id and units, they would still be separate objects.
  • You can see an object’s identifier using id():
print("id(s1):", id(s1))
print("id(s2):", id(s2))
Output
id(s1): 127831146606672
id(s2): 127831159223456

Caution with Assignment

When you create a LabSample instance, the variable does not store the whole object.

  • It stores a reference (address) to the object in memory.

What happens if we assign one variable to another?

# Reinitialize s1
s1 = LabSample("PH-017", "pH")

# Reinitialize s2
s2 = LabSample("V-204", "V")

# Assigning a new variable sx to s1
sx = s1

The assignment sx = s1 does not create a new LabSample.

It copies the reference, so s1 and sx now point to the same object:

  • Both s1 and sx point to the same address in memeory,
  • and have the same object IDs.
# Comparing their addresses
print(s1)
print(sx)
Output
<__main__.LabSample object at 0x7443021584d0>
<__main__.LabSample object at 0x7443021584d0>
# Comparing their IDs
print("id(s1):", id(s1))
print("id(sx):", id(sx))
Output
id(s1): 127831146595536
id(sx): 127831146595536

Why this Matters

1. Changing the object through one variable affects what the other variable sees:

print(f"s1 measurements: {s1.measurements}")

print("Adding measurement to sample sx")
sx.add_measurement(6.98) # Adding a mesaurement to sx
print(f"s1 measurements: {s1.measurements}")
print(f"sx measurements: {sx.measurements}")  # s1 also shows the new measurement
Output
s1 measurements: []
Adding measurement to sample sx
s1 measurements: [6.98]
sx measurements: [6.98]

2. If s1 is later reassigned to a different object, that does not change what sx references:

# Reassigning s1 to s2
s1 = s2  # s1 now references a different object
# s1 no longer referrences the same object in memory as sx
print(f"s1 referrences address: {s1}")
print(f"s2 referrences address: {s2}")
print(f"sx referrences address: {sx}")
Output
s1 referrences address: <__main__.LabSample object at 0x74430215b050>
s2 referrences address: <__main__.LabSample object at 0x74430215b050>
sx referrences address: <__main__.LabSample object at 0x7443021584d0>
# s1 measurements are now empty
print(f"s1 measurements: {s1.measurements}")
print(f"s2 measurements: {s2.measurements}")
print(f"sx measurements: {sx.measurements}")
Output
s1 measurements: []
s2 measurements: []
sx measurements: [6.98]

Printing Objects

Default String Representation __str__

In earlier examples, we printed details about a LabSample by directly accessing its attributes (for example, sample_id, units, and measurements). The downside is that we need to know the internal structure of the class in order to print something meaningful.

It is often more convenient if the object itself knows how to describe itself as a string. In Python, we do this by defining a special method called __str__. This method should return a string that represents the object in a useful, readable way.

The method signature is:

def __str__(self):

Remark: Methods that start and end with double underscores (like __init__ and __str__) are special methods in Python. We will see more of these later, but for now we will focus on __str__.

Adding str to LabSample

Here is a version of LabSample with a simple __str__ method:

class LabSample:

    def __init__(self, sample_id, units):
        self.sample_id = sample_id
        self.units = units
        self.measurements = []  # list of floats

    def add_measurement(self, value):
        self.measurements.append(float(value))

    def __str__(self):
        # Build a readable one-line summary of the object
        n = len(self.measurements)
        return f"sample id: {self.sample_id}, units: {self.units}, sample size: {n}"

Remarks:

  • We build the output string using the object’s attributes: self.sample_idand self.units.

  • defined a new variable n that holds the number of samples in self.measurements

# Initializing two instances of LapSamples s1 and s2
s1 = LabSample("PH-017", "pH")
s2 = LabSample("V-204", "V")

# Adding two measurements to s1
s1.add_measurement(6.98)
s1.add_measurement(7.01)

# Adding 1 measurement to s2
s2.add_measurement(4.93)

print(s1)
print(s2)
Output
sample id: PH-017, units: pH, sample size: 2
sample id: V-204, units: V, sample size: 1

Remark:

By defining __str__, you are overriding the default printing behaviour for your class. The default printing behaviour shows a generic object description:

print(s1)

Output:

<__main__.LabSample object at 0x7acb5d3d3590>

With __str__, print(s1) uses the string you return from __str__ instead.

Class Comments

Adding Docstrings

It is common to include a short description of what a class represents and what it is used for.

  • In Python, this is usually done with a docstring placed directly under the class header.
  • A docstring is written using triple quotes (""" ... """) and can span multiple lines.
class LabSample:
    """Represents a lab sample with repeated measurements (e.g., pH, voltage, mass)."""

    def __init__(self, sample_id, units):
        self.sample_id = sample_id
        self.units = units
        self.measurements = []  # list of floats

    def add_measurement(self, value):
        self.measurements.append(float(value))
print(LabSample.__doc__)
Output
Represents a lab sample with repeated measurements (e.g., pH, voltage, mass).

Instance Methods

An instance method is behaviour that belongs to an object (an instance) of a class.

Instance methods always include self as the first parameter.

  • self gives the method access to the object’s own attributes (like self.measurements).

Instance methods can:

  • take input parameters,
  • return a value,
  • or do both.

Example:

Suppose we want each LabSample to be able to report the average of its measurements:

def mean(self):
    """Return the average measurement, or None if there are no measurements."""
    if len(self.measurements) == 0:
        return None
    return sum(self.measurements) / len(self.measurements)
class LabSample:
    """Represents a lab sample with repeated measurements (e.g., pH, voltage, mass)."""

    def __init__(self, sample_id, units):
        self.sample_id = sample_id
        self.units = units
        self.measurements = []

    def add_measurement(self, value):
        self.measurements.append(float(value))

    # Adding a new method mean()
    def mean(self):
        """Return the average measurement, or None if there are no measurements."""
        if len(self.measurements) == 0:
            return None
        return sum(self.measurements) / len(self.measurements)
    
    def __str__(self):
            # Build a readable one-line summary of the object
            n = len(self.measurements)
            return f"sample id: {self.sample_id}, units: {self.units}, sample size: {n}"
s1 = LabSample("PH-017", "pH")
s1.add_measurement(6.98)
s1.add_measurement(7.01)

avg = s1.mean()
print(f"Mean for {s1.sample_id} = {avg} {s1.units}")
Output
Mean for PH-017 = 6.995 pH

Deleting Objects

The keyword del

After you create an object (an int, a bool, or a user-defined object like LabSample), you may later stop using it.

  • Python provides the keyword del to remove a variable name.
  • This breaks the connection between the variable and the object it referenced.
  • After that, you can no longer use that variable to access the object.
s1 = LabSample("PH-017", "pH")
print(s1)
Output
sample id: PH-017, units: pH, sample size: 0
del s1
print(s1)
Output
---------------------------------------------------------------------------
NameError                                 Traceback (most recent call last)
Cell In[23], line 2
      1 del s1
----> 2 print(s1)

NameError: name 's1' is not defined

Why might you delete an object?

Sometimes you delete objects to free up memory when you know they are no longer needed (especially if they store lots of data).

You might also delete a variable to prevent accidental reuse later in a long program or notebook (so you don’t mistakenly keep working with old data).

Intrinsic attributes

(built-in information on classes and objects)

Common intrinsic attributes on classes

  • __name__ : the name of the class
  • __module__ : the module (file) where the class is defined
  • __bases__ : the base class(es) it inherits from (we’ll return to inheritance later)
  • __dict__ : a dictionary containing the class contents (attributes, including methods)
  • __doc__ : the class docstring

Common intrinsic attributes on objects (instances)

  • __class__ : the class that the object is an instance of
  • __dict__ : a dictionary of the object’s attributes (its stored data)
# Example: printing intrinsic attributes for `LabSample`

# Create an instance
s1 = LabSample("PH-017", "pH")

print("-"*12)
print("Class attributes")
print(LabSample.__name__)
print(LabSample.__module__)
print(LabSample.__doc__)
print(LabSample.__dict__)

print("-"*12)
print("Object attributes")
print(s1.__class__)
print(s1.__dict__)
