Recursion Algorithm Patterns

Three Common Recursion Patterns

Many recursive algorithms fall into one of the following patterns.

Understanding these patterns helps us recognize when recursion is a natural solution.

  • Divide-and-Conquer
  • Backtracking
  • Tree Algorithms

Divide-and-Conquer

Divide-and-conquer algorithms solve a problem by:

  1. Dividing the problem into smaller subproblems
  2. Solving those subproblems recursively
  3. Combining the results

Examples include:

  • Merge Sort
  • Binary Search
  • Tower of Hanoi Problem

Each recursive call works on a smaller version of the same problem.

Backtracking

Backtracking is used when we must explore many possible solutions.

The algorithm repeatedly:

choose → recurse → undo

If a choice does not lead to a valid solution, the algorithm backtracks and tries a different option.

Examples include:

  • generating permutations
  • solving Sudoku
  • maze solving

Tree Algorithms

In computer science, a tree is a hierarchical structure made of nodes connected by edges:

  • The top node is called the root
  • Nodes that contain other nodes are called internal nodes
  • Nodes with no children are called leaf nodes

Tree algorithms operate on these tree hierarchical data structures where each node may contain child nodes (smaller subtree structures).

Because each subtree is itself a smaller tree, recursion is a natural way to process them.

Example:

Directory traversal algorithm:

  • Root Directory projects/ –> Root Node
  • Subdirectories (images/, archive/, etc) –> Internal Nodes
  • Files (report.txt, data.csv, etc) –> Leaf Nodes

Tower of Hanoi

(Divide-and-Conquer)

Tower of Hanoi

The Tower of Hanoi puzzle was invented by the French mathematician
Edouard Lucas in 1883.

The puzzle consists of:

  • Three poles
  • A stack of disks, each smaller than the one beneath it

The goal is to move the entire stack from one pole to another under the following conststraints:

  1. Only one disk may be moved at a time.
  2. A larger disk can never be placed on top of a smaller disk.

3 Disk Solution

Hint: Move everything except the bottom disk somewhere else:

General Solution

Let nn denote the number of disks.

Base Case

If only one disk remains on pole AA (n=1n = 1), move the disk from A→BA \rightarrow B.

Recursive Steps

To move nn disks from A→BA \rightarrow B:

  1. Move n−1n-1 disks from A→CA \rightarrow C.
  2. Move disk nn from A→BA \rightarrow B.
  3. Move n−1n-1 disks from C→BC \rightarrow B.

Notice that the recursive steps reduce the problem from nn disks to n−1n-1 disks, which eventually reaches the base case n=1n=1.

Recursive Algorithm

We want to write a function

moveTower(n, fromPole, toPole, withPole)

that solves the Tower of Hanoi problem.

Here:

  • n is the number of disks we want to move
  • fromPole is the pole the disks start on
  • toPole is the pole we want to move the disks to
  • withPole is the extra pole we use temporarily

A very important idea is that these parameters describe the role of each pole in the current call. They are not permanently tied to "A", "B", or "C".

Step 1: Base Case

The simplest case is when there is only one disk to move.

If n == 1, we do not need any recursion. We simply move the disk directly from the source pole (fromPole) to the destination pole (toPole).

So the base case is:

if n == 1:
    print(f"Move disk {n} from {fromPole} to {toPole}")

Step 2: Recursive calls

To move n disks from fromPole to toPole:

  1. Move the top n-1 disks out of the way (from fromPole to withPole)
  2. Move disk n to the destination (from fromPole to toPole)
  3. Move the n-1 disks back on top of disk n (from withPole to toPole)

This gives the recursive structure of the algorithm:

    moveTower(n-1, fromPole, withPole, toPole)              # Step 1
    print(f"Move disk {n} from {fromPole} to {toPole}")     # Step 2
    moveTower(n-1, withPole, toPole, fromPole)              # Step 3

Putting Everything Together

def moveTower(n, fromPole, toPole, withPole):
    if n == 1:
        print(f"Move disk {n} from {fromPole} to {toPole}")
    else:    
        moveTower(n-1, fromPole, withPole, toPole)
        print(f"Move disk {n} from {fromPole} to {toPole}")
        moveTower(n-1, withPole, toPole, fromPole)

moveTower(3, "A", "B", "C")
Output
Move disk 1 from A to B
Move disk 2 from A to C
Move disk 1 from B to C
Move disk 3 from A to B
Move disk 1 from C to A
Move disk 2 from C to B
Move disk 1 from A to B

Generating Permutations

(Backtracking)

Permutations

A permutation is an ordering of the elements of a collection.

For example, the permutations of [A,B,C] are:

[A,B,C]
[A,C,B]
[B,A,C]
[B,C,A]
[C,A,B]
[C,B,A]

To generate permutations recursively we use the backtracking technique:

  1. Choose an element
  2. Recurse on the remaining problem
  3. Undo the choice so another possibility can be explored
choose → recurse → undo

How the Algorithm Works

The idea is to fix one position at a time.

At position start, we try placing every remaining element there.

For each choice:

  • we swap that element into the current position
  • recursively generate permutations of the remaining positions
  • then swap back to restore the original list

The swap-back step is the backtracking step.

Without it, the list would remain modified and the next branch of the search would be incorrect.

Example

Starting with:

[A,B,C]

Recursive Algorithm

Recursion Case

Instead of working out the base case first, we will instead work through the recursion case:

# Recursive Case
for i in range(start, len(items)):
    # choose (swap)
    items[start], items[i] = items[i], items[start]

    # recurse
    permute(items, start + 1)

    # undo (backtrack)
    items[start], items[i] = items[i], items[start]

Base Case

if start == len(items):
    print(items) # Permutation Found
    return

Putting Everything Together

def permute(items, start=0):

    # Base Case
    if start == len(items):
        print(items) # Permutation Found
        return

    # Recursive Case
    for i in range(start, len(items)):
        # choose (swap)
        items[start], items[i] = items[i], items[start]

        # recurse
        permute(items, start + 1)

        # undo (backtrack)
        items[start], items[i] = items[i], items[start]


permute(['A','B','C'])
Output
['A', 'B', 'C']
['A', 'C', 'B']
['B', 'A', 'C']
['B', 'C', 'A']
['C', 'B', 'A']
['C', 'A', 'B']

Directory Search Algorithm

(Tree Algorithm)

Computing Directory Size

Another practical application of recursion is searching through a directory structure.

In this example our goal is to compute the total size of a directory, including:

  • all files in the directory
  • all files in its subdirectories

Directories Structure

For a directory system:

  • the root directory is the root node
  • subdirectories are internal nodes
  • files are leaf nodes

Because directories can contain other directories, the structure naturally forms a tree of directories and files.

Directory Structure Example

To compute the total size of project/, we must add:

  • sizes of files in project/
  • sizes of files in images/
  • sizes of files in archive/
  • sizes of files in logs/

Observations:

  • A directory contains smaller directories
  • The problem of computing the size of a directory is the same problem as:
    • computing the size of a subdirectory.

This makes the problem ideal for recursion.

Recursive Strategy

To compute the size of a directory:

  1. Look at each item in the directory.
  2. If the item is a file, add its size. (Base Case)
  3. If the item is a subdirectory, recursively compute its size. (Recursice Case)
  4. Add everything together.

Python Tools for Directory Traversal

Useful functions from the built-in os module:

Function Description
os.listdir() lists items in a directory
os.path.isfile() checks if a path is a file
os.path.isdir() checks if a path is a directory
os.path.getsize() returns the file size

Recursive Implementation

Search Current Directory:

Look at each item in the directory and extract it’s path:

for item in os.listdir(path):
    full_path = os.path.join(path, item)                # Extracting item path

Base Case:

If the item is a file, add its size:

if os.path.isfile(full_path):                           # Base case
            total_size += os.path.getsize(full_path)    # Add file size

Recursive Case:

If the item is a subdirectory, recursively compute its size:

elif os.path.isdir(full_path):                          # Recursive case
    total_size += get_directory_size(full_path)         # Recursive call

Putting Everything Together:

import os

def get_directory_size(path):
    total_size = 0

    for item in os.listdir(path):

        full_path = os.path.join(path, item)

        if os.path.isfile(full_path):                       # Base Case
            total_size += os.path.getsize(full_path)

        elif os.path.isdir(full_path):                      # Recursive Case
            total_size += get_directory_size(full_path)

    return total_size
