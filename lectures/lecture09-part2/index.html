ArrayList Initialization

class ArrayList:

    def __init__(self, capacity=4):
        self._capacity = capacity
        self._size = 0
        self._data = [None] * capacity

Internal variables:

  • _data –> underlying storage
  • _size –> number of stored elements
  • _capacity –> maximum elements before resizing

Example:

lst = ArrayList()

Note: The double underscore __ repersents None in the above diagram

ArrayList _resize

When the array becomes full, a larger array must be allocated.

def _resize(self):

    # Create a new array with larger capacity
    new_capacity = self._capacity * 2
    new_data = [None] * new_capacity

    # copy elements to new array
    for i in range(self._size):
        new_data[i] = self._data[i]

    # replace the old storage
    self._data = new_data
    self._capacity = new_capacity

Notes:

  • This resizing strategy ensures that append operations remain efficient.
  • The double underscore __ repersents None in the above diagram

ArrayList append

Appending means adding an element at the end of the list.

def append(self, value):

    if self._size == self._capacity:    # Check if the array is full
        self._resize()                  # Resize if necessary

   
    self._data[self._size] = value      # Insert element at index `size`
    self._size += 1                     # Increase `size`

Note:

  • Appending is usually very fast.
  • The double underscore __ repersents None in the above diagram

ArrayList insert

Inserting into the middle requires shifting elements to the right.

def insert(self, index, value):
    if index < 0 or index >= self._size:        # Catch index out of range
        raise IndexError("Index out of range")

    if self._size == self._capacity:            # Check if the array is full
        self._resize()                          # Resize if necessary

    for i in range(self._size, index, -1):      # Shifting elements to the right
        self._data[i] = self._data[i-1]

    self._data[index] = value                   # Inserting new element
    self._size += 1                             # Update size

Note: The double underscore __ repersents None in the above diagram

ArrayList remove

Removing into the middle requires shifting elements to the left.

def remove(self, index):
    if index < 0 or index >= self._size:        # Catch index out of range
        raise IndexError("Index out of range")

    removed = self._data[index]                 # Remove item at give indexed
    
    for i in range(index, self._size - 1):      # shift elements to the left
        self._data[i] = self._data[i+1]

    self._data[self._size-1] = None             # optional: help garbage collector
    self._size -= 1                             # Update size
    return removed

Note: The double underscore __ repersents None in the above diagram

Additions

We will also add the following methods to help with printing:

  • __str__ (show a human-readable repersentation)
  • __repr__ (show the internal structure)
def __str__(self):

    elements = []

    for i in range(self._size):
        elements.append(str(self._data[i]))

    return "[" + ", ".join(elements) + "]"

def __repr__(self):
    return f"ArrayList(size={self._size}, capacity={self._capacity}, data={self._data})"

Structure

Node Structure

class Node:

    def __init__(self, data):
        self.data = data
        self.next = None

Internal variables:

  • data –> element contained in the node
  • next –> reference to the next node in the linked list

Example:

temp = Node(93)

LinkedList Structure

class LinkedList:

    def __init__(self):
        self.head = None
        self._size = 0

Internal variables:

  • head –> reference to the first node in the linked list (or None if the list is empty)
  • size –> the number of nodes in the linked list

Example:

mylist = LinkedList()

LinkedList Traversal

Linked lists do not support direct indexing like arrays. So we implement the protected traveral method _traverse.

This helper method is used by other operations such as:

  • get(i)
  • set(i, x)
  • insert(i, x)
  • remove(i)

All of these operations require traversing the list to locate a node.

LinkedList Traversal

def _traverse(self, index):
    """Return the node at position index."""

    # Check that the index is valid
    if index < 0 or index >= self._size:
        raise IndexError("Index out of range")

    # Start traversal at the head of the list
    current = self.head

    # Move forward one node at a time
    # After k steps, current points to node k
    for _ in range(index):
        current = current.next

    # Return the node located at the given index
    return current

LinkedList append

def append(self, value):
    """
    Add a new node to the end of the list.
    """

    # Create the node that will be added
    new_node = Node(value)

    # Case 1: the list is empty
    # The new node becomes the head of the list
    if self.head is None:
        self.head = new_node

    else:
        # Case 2: the list already contains nodes
        # Use the helper method to locate the last node
        last = self._traverse(self._size - 1)

        # Link the final node to the new node
        last.next = new_node

    # Update the size of the list
    self._size += 1

LinkedList add

def add(self, value):
    """
    Add a new node to the front (head) of the list.
    """

    # Create the node that will be added
    new_node = Node(value)

    # Step 1: point the new node to the current head
    new_node.next = self.head

    # Step 2: update head to reference the new node
    self.head = new_node

    # Update the size of the list
    self._size += 1

LinkedList add

Important detail:

  • The order of these two lines matters:
temp.next = self.head
self.head = temp
  • First we connect the new node to the existing list.
  • Then we update the head pointer.

If we updated head first, we would lose the reference to the original list.

LinkedList remove

def remove(self, index):

    # Ensure the index is valid
    if index < 0 or index >= self._size:
        raise IndexError("Index out of range")

    # Case 1: removing the head node
    if index == 0:
        removed = self.head.data

        # Update the head to point to the next node
        self.head = self.head.next

    else:
        # Step 1: Locate the node before the one we want to remove
        prev = self._traverse(index - 1)

        # Step 2: Store the value being removed
        removed = prev.next.data

        # Step 3: Bypass the node being removed
        prev.next = prev.next.next

    # Update the size of the list
    self._size -= 1

    return removed
