Overview

You have two options: install python, or install anaconda package manager. On linux I like to just install python and do things by hand, but I have found in Windows the Anaconda package manager for python is very useful.

Installation

  • anaconda - full anaconda environment, graphical user interface (GUI) used to install things. Can make life easier, especially if you're highly visual and nervous with the command line still.
  • miniconda - a smaller commandline version of anaconda. great if you want to get your hands dirty
    • when installing either conda, use both advanced options (add to PATH and default)
  • python download just pure python and do everything yourself! I really suggest using pip or python -m pip to install everything for you.

Test your install:

Open terminal: PowerShell (WinKey > PowerShell)

  • verify conda: conda --version
  • verify python: python --version or python3 --version

If you installed full Anaconda, open Anaconda Navigator from your apps list.

Installing new packages:

for conda you can use the terminal:

  • conda install <package-name>
  • (e.g., conda install numpy)
  • or you can use the Anaconda Navigator

if you don't have conda:

  • python -m pip install --user <package-name>
  • (e.g., python -m pip install --user numpy)

this may also work:

  • pip install --user <package-name>

Using Environments

Python environments are useful sometimes, like a sandbox to keep packages separate and custom for each specific project

create an environment:

  • python -m venv /path/to/new/virtual/environment
  • (e.g., python -m venv .venv)

activate environment:

  • windows: .\path\to\new\virtual\environment\Scripts\activate

    • (e.g., .\.venv\Scripts\activate)

    • If you are trying to activate your environment and running into permission issues. Try first executing this command

      Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

      Then try activating your virtual environment.

  • linux or mac: source /path/to/new/virtual/environment/bin/activate
    • (e.g., source .venv/bin/activate)

When you activate an environment you will see it listed in your terminal:

now when you use conda or pip to install something it will be in THIS python environment, not your system installation.
